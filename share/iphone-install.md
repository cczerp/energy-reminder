# Installing MindCue on an iPhone (free, with a computer)

This installs the app with a free Apple ID. **The install lasts 7 days.** Repeat the same steps to refresh it (your notes stay).
You need: the iPhone, its USB cable, a Windows PC or Mac, and an Apple ID (a spare one is fine).

1. On the computer, install **Sideloadly** (sideloadly.io). On Windows, install iTunes and iCloud from apple.com, not the Microsoft Store.
2. Download `mindcue.ipa` from the **latest-ios** release on the GitHub Releases page.
3. Plug the iPhone in and tap **Trust** if it asks.
4. Open Sideloadly. Drag `mindcue.ipa` onto it, type the Apple ID, and press **Start**. Enter the Apple ID password when asked.
5. On the iPhone: **Settings → Privacy & Security → Developer Mode → on**, then restart when it asks.
6. On the iPhone: **Settings → General → VPN & Device Management**, tap the Apple ID, tap **Trust**.
7. Open **MindCue** and allow notifications. For leave-home reminders, allow location, then **Always** when it asks.

To refresh: plug in, open Sideloadly, drag the file again, Start. Do it every week (any day within the 7).
