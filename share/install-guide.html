Install Mindful

For Android phones. It takes about two minutes. (This does not work on iPhone.)

Step 0: Get the file Open your phone's Camera, point it at this square, and tap the link that appears.
No camera option? Open the Internet app and type:
github.com/cczerp/energy-reminder/releases/latest
then tap mindful.apk.
  1. If the phone says the file "can harm your device", tap Download anyway (or OK). When it finishes, tap Open.
  2. If it says "your phone isn't allowed to install unknown apps from this source": tap Settings, switch on Allow from this source, then press the Back arrow.
  3. Tap Install.
  4. If a Google Play Protect box appears, tap More details, then tap Install anyway.
    Important: do not tap Got it or OK. Those close the box without installing.
  5. When it says App installed, tap Open. You will see a purple screen with "I'm in a funk" at the top.
  6. Tap the purple Allow notifications button and then Allow. That's how Mindful reminds you.
All done! Tap Settings (bottom right of Mindful) any time to choose how many reminders you want.

If something goes wrong

"App not installed" — an older copy of Mindful is already on the phone. Press and hold the Mindful icon, tap Uninstall, then start again from Step 0. (Nothing important is lost unless you have already written notes in the app.)
I see a yellow message or a blank purple screen — take a screenshot (press Power + Volume Down together) and send it to the person who gave you this sheet.
I tapped "Got it" and nothing installed — that's normal. Start again from Step 0 and tap More details → Install anyway this time.
The download didn't start — in your phone's Internet app, open the link again and tap the mindful.apk file name.

Getting updates later

Scan the same square again. Install it the same way, without uninstalling. Your settings stay. To check which version you have, open Today in Mindful and look at the bottom: "Mindful · build N".
