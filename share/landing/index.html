Timbre Tamer

Gentle reminders and a log for your mindfulness practice. Works offline. For Android phones.

Download for Android

Open this page on your phone, not a computer. It does not work on iPhone.

Install it in four steps

  1. Tap Download for Android. If the phone says the file can harm your device, tap Download anyway, then Open.
  2. If it says it can't install apps from this source, tap Settings, switch on Allow from this source, then press the back button.
  3. Tap Install.
  4. If Google Play Protect appears, tap More details, then Install anyway. (Not "Got it" or "OK" — those do not install it.)

Then open Timbre Tamer and tap Allow notifications. That's how it reminds you.

Updating? Download again and install it the same way. Your notes and settings stay.
